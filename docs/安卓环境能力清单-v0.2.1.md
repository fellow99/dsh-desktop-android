## A. 环境标识（本工程 vs 两条鸿蒙路线）

| 项 | **Android Edition（本工程）** | ArkWeb 路线（`dsh-desktop-ark`） | Electron on HarmonyOS（`dsh-desktop-hos`，基准） |
|---|---|---|---|
| 界面渲染 | 系统 **WebView**（不随包带内核；G-WV ≥110 门禁） | 系统 ArkWeb | Electron 37 内置 Chromium |
| Node 运行时 | 进程内 `libnode.so` **v24.22.1（small-icu）**（`node::Start`） | 进程内 libnode v24.2.0 | Electron 内置 Node 22.17 |
| 平台适配方式 | 上游**零补丁**：`android` profile + `@dsh-android/bundle` + 5 条带标记垫片（S1 flock / S2 sharp / S3 require-builtin / S4 附件 fsync / S5 fs-link·symlink）+ seam 插件 + 装配期补丁（S4 同款纪律：唯一锚点+标记+幂等） | 零补丁：6 条垫片 | 13 个源码补丁 |
| 运行时形态 | **JIT 可用**（自分发无 ACL 概念；转译环境实测跑通） | 默认 `--jitless` 零 ACL；`jit` 变体需 ACL | JIT 需受限权限 |
| 沙箱策略 | `workspace-write`（`sandbox: none`，策略层 + 上游 `fs-sandbox` fail-closed） | 同左 | `workspace-write` + 审批 `ask` |
| 包体 | APK ≈ **134.6 MB**（引擎 81.5 MB 不压缩 + 载荷 tar 压缩 47.8 MB） | HAP ≈ 88 MB | 数百 MB |
| 权限面 | `MANAGE_EXTERNAL_STORAGE`（仅 `full` flavor，`store` flavor SAF-only）+ 通知 + 前台服务（数据同步） | 三根目录 ACL 已撤销、零受限权限 | 桌面目录权限仍声明 |
