# 安卓常规终端命令能力分析（dsh-desktop-android）

> 主题：在 Android 环境中，**除预置 CLI（node / python / git / uv / pnpm 及 npm/npx/corepack/pip）外**，
> Agent 的 bash / 终端面板能调用哪些「常规终端命令」，能力源头来自哪里。
> 分析方式：源码取证（`@dsh-android/subprocess` 白名单）+ 真机实测（M2105K81C，API 30，arm64-v8a，2026-11-07）。
> 对应规格：`specs/112-cli-integration`（CLI 五件套）的剖面补遗；此文档记录的是系统侧常规命令，与预置 CLI 互补。

## 一句话结论

Agent 的 bash / 终端里可调用的常规命令 = **Android 系统固件 `/system/bin`（417 条）+ `/system/xbin`（6 条）**，
由四层决定：

> **可执行白名单（决策层）→ mksh（执行器）→ toybox / 框架 / 独立二进制（本体层）→ 固件镜像（源头）**。

`/vendor/bin`（373）、`/apex`、`/product`、`/system_ext`、`/odm` 固件里存在但**不在可执行白名单**，Agent 不可调用。

## 一、能力源头（四层）

| 层 | 内容 | 证据 |
|---|---|---|
| **① 决策层（谁允许执行）** | `@dsh-android/subprocess` 的 `isAllowedExecutable()`：realpath 规范化后**只放行 4 个根**——`/system/bin/**`（＋`/system/bin/toybox`）、`nativeLibraryDir`（预置 CLI .so）、会话 workspace（用户脚本）。PATH 解析时枚举候选，不满足白名单即**跳过**。相对路径（含 `/` 的裸路径）被拒绝（解析基准 `/` 无意义）。 | `packages/subprocess-android/lib/index.js`（`isAllowedExecutable` / `resolveProgram` / `DEFAULT_PATH`） |
| **② 执行器层** | dsh「bash 工具」实际 exec **`/system/bin/sh` = mksh**（310KB 实体，非 bash）；PTY 终端面板同源（node-pty → `/system/bin/sh`，哨兵协议 shell）。 | `SYSTEM_SHELL='/system/bin/sh'`；真机 `ls -l /system/bin/sh` |
| **③ 本体层** | 见「二、本体层分类」——toybox applets / mksh 内建 / 独立二进制 / 框架命令。 | 真机 `command -v` + `readlink` |
| **④ 固件层** | `/system/bin`、`/system/xbin`、`/vendor/bin`、`/apex`、`/product`、`/system_ext`、`/odm` 均为系统镜像内容；Android 默认进程 PATH 会带 `/product、/apex、/system_ext、/odm、/vendor`，但子进程**只放行 `/system/bin`**。 | 真机 `ls` 各目录 |

### ① 决策层代码要点（`subprocess-android`）

```text
- 允许根：/system/bin/** ∪ /system/bin/toybox ∪ nativeLibraryDir(DSH_ANDROID_NATIVE_LIB_DIR) ∪ workspace
- 裸命令 → 沿 PATH 找 → 逐候选 isAllowedExecutable() 过滤
- 带 / 的绝对路径 → 白名单外直接拒（错误文案点名四个根）
- 默认 PATH（无注入时）：/system/bin:/system/xbin:/usr/bin:/bin
```

### 2.2 mksh（`/system/bin/sh`，执行器 + 内建）

- shell 关键字/内建：`echo export test [ ] let time cd pwd set unset read eval ` 敲 ` $ ` 等（POSIX+ksh 方言）。
- **不是 bash**：`[[ ]]`、`declare`、`$'\n'`、`shopt` 等 bash 专有语法不可用。
- 深坑：mksh 的 `echo` 不解析转义；glob 为 ksh 语义。

### 2.3 独立系统二进制（实体，非 toybox）

| 命令 | 大小 | 说明（真机 `ls -l`） |
|---|---|---|
| `awk` | 137KB | 独立 awk（非 toybox），正则/表计算补齐 |
| `bc` | 81KB | 任意精度计算 |
| `curl` | 478KB | **curl 7.67.0 (Android) BoringSSL**——系统自带、真实可用，独立于 git 的 HTTP(S) 能力源 |
| `ip` | 403KB | 真实 iproute2 工具（app 域 netlink 被拒，见 §三） |
| `ping` | 38KB | ICMP 回环可用 |

## 三、实测可达性（app 沙箱域，SELinux `untrusted_app`/`runas_app`）

### ✅ 可用

| 类 | 实测 |
|---|---|
| 文本/文件 | toybox 全集：`grep/egrep/fgrep`、`sed`、`find`、`xargs`、`tr`、`cut`、`tar -c`(归档 OK)、`sha256sum`、`date`… |
| 数据处理 | `awk '{sum+=$2} END{print sum}'`（语法可用）、`sed 's/y/YY/'`、`tr a-z A-Z` |
| 网络 | **`curl` 外带**：`curl -s -m5 -o /dev/null -w "%{http_code}" http://connectivitycheck.gstatic.com` → 可达（404 即为连通）；`ping -c1 127.0.0.1` OK |
| 框架 | `pm list packages`（241 包）、`getprop`、`logcat`（读） |
| 哈希 | `md5sum` `sha1sum` `sha256sum` `cksum`（校验/取证） |

### ⛔ SELinux / 平台限制（解析得到但执行被拒）

| 命令 | 实测 |
|---|---|
| `ip addr show` | `Cannot bind netlink socket: Permission denied` |
| `setprop x 1` | `Failed to set property ...`（写属性被拒） |
| `chroot /data /bin/true` | `Operation not permitted` |
| `reboot` | `Permission denied` |
| `mount` | 仅只读展示（`/dev/block/dm-5 on / type ext4 (ro,seclabel...)`），不可改变挂载 |
| `ls /sdcard` | `Permission denied`（scoped storage；应用工作区在 `files/`，非公共目录） |

### ❌ 不存在

`su`（**无 root**）、`bash` `zsh` `python` `perl` `gcc` `apt` `dpkg` `wget` `zip`、`/apex` 运行期二进制（白名单外）。

## 四、对 Agent 的意义

1. **网络能力源头 = 系统 `curl`**（真实、BoringSSL，外带连通）——Agent 拥有独立于 git/http 协议栈的拉取与上报能力。
2. **文本处理链完整**：`awk + sed + grep + cut + base64/xxd + python(预置 CLI)`，分析/裁剪/聚合类任务不缺工具。
3. **shell 是 mksh 不是 bash**：`echo`/glob/`[[ ]]`/转义语义按 POSIX+ksh；给终端面板写命令时避开 bash 专有语法。
4. **跑不进 `/vendor` `/apex` 的二进制**：厂商调试工具、APEX 运行时命令对 Agent 刻意不可达（护栏收缩面，与能力清单 T-023「护栏仅系统 bin」一致）。
5. **网络命令优先级**：需要通用 HTTP 时优先 `curl`（独立、已测）；`git` 走专用协议栈（credential/受控）。

## 五、复现方法

```bash
# 1) 白名单代码
sed -n '223,305p' packages/subprocess-android/lib/index.js   # isAllowedExecutable / resolveProgram

# 2) 真机枚举（与 Agent 相同 app 沙箱域）
adb shell run-as org.fellow99.dsh.android sh -c '
  export PATH=/system/bin:/system/xbin:/bin
  id                                            # uid + SELinux context
  toybox | wc -w                               # 196 applets
  for c in ls cat grep sed awk find curl tar vi xxd ip ping dumpsys am pm su bash; do
    command -v $c 2>/dev/null || echo "$c ABSENT"
  done
'

# 3) 可达性抽样
adb shell run-as org.fellow99.dsh.android sh -c '
  ping -c1 -W1 127.0.0.1
  curl -s -m5 -o /dev/null -w "%{http_code}\n" http://connectivitycheck.gstatic.com
  ip addr show wlan0 2>&1 | head -1          # netlink denied
  pm list packages 2>/dev/null | wc -l
'
```

> 取证：以上实测定于 2026-11-07，设备 M2105K81C / Android 11 / API 30 / arm64-v8a；
> 各 App 执行器的路径与可达性随系统版本与 SELinux 策略变化，以实机复测为准。
