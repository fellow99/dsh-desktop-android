## G4 实证（本报告核心）

**现象**：`runProfile` 抛出 `dsh: startup failed: 1 required plugin did not activate`，11 个上游插件导入失败，其中 **`agent-loop` 为 required → 启动中止** → 事件循环空 → `node::Start` 30s 后返回 rc=0 → 应用按终态如实呈现"Node 提前退出"。

**两类失败（同一根因：引擎无 ICU）**：

1. `SyntaxError: Invalid regular expression: /^[\p{XID_Start}_]\p{XID_Continue}*$/u: Invalid property name in character class`（`\p{L}`、`\p{N}` 同类）——Unicode 属性转义在无 ICU 的 V8 上**编译期**即失败，涉及 tool-working-directory / subagent / session-checkpoint-policy / mcp-resources / tools / **agent-loop(required)** / llm-deepseek-* / schedule / cordis-host-runner。
2. `ReferenceError: Intl is not defined`（@sindresorhus/is，otel 插件）。

**探针佐证**：`probes.intl = {typeofIntl:"undefined"}`（bootstrap 轻量探针在插件加载前已如实记录，预测与实况一致）。

**为什么无法用垫片救**：失败发生在 ESM **源码编译期**（正则字面量），任何运行期 polyfill 都无法介入；源码改写式 loader 违反 §5.3 白名单纪律（超范围改写上游语义）。

**修复路径（规划 §10.1 G4 兜底，唯一可行）**：
1. 用 `aosp-node-runtime` 的构建管线（`scripts/build-node-android.sh` / GitHub Actions `build-node-android.yml`）重编 Node v24.22.1：`./configure … --with-intl=small-icu`（其余参数不变）；
2. 更新 `runtime.lock.json`（新 sha256/size + 保留 intl 说明）→ `tools/provision.mjs` 投放 → 本工程 `scripts/provision-engine.mjs` 对账 → 重打包；
3. 复测本报告全部 ⏳/⛔ 项（宿主开机 → G1 → 功能用例）。
> 注意：G4 与设备无关（引擎级），**真机测试同样被阻断**；引擎修复后模拟器/真机共用同一修复。
