# dsh-desktop-android

**DSH Desktop (Android Edition)** — runs [deepseek-harness](../deepseek-harness) (dsh) on Android as a
desktop delivery with an **in-process Node + the system WebView**.

- **Version**: 0.2.2 (`versionCode` 202) ｜ upstream baseline `dsh-v0.2.2-rc.1` ｜ engine libnode **v26.13.0** (small-icu)
- **Stack**: Kotlin (View system) · system WebView · in-process `libnode.so` (`node::Start`, JNI slot-table bridge) · dsh Host (HTTP + WebSocket)
- **Adaptation principle**: **zero upstream patches** — `android` profile + `@dsh-android/bundle` (three kinds of patch operations) + tagged shims/materialization-time patches + bespoke seam plugins (`packages/*-android`)

## Runtime model

```
MainActivity (foreground UI)
  └─ DshRuntime: boots libnode in-process → dsh Host (listens on 127.0.0.1:<random port> only)
  └─ WebShellView (WebView) → loads http://127.0.0.1:<port>/?token=<one-time token>
  └─ HostCapabilities: Kotlin↔Node capability bridge (frozen 17 names, JSON in/out, handler never throws)
  └─ KeepAliveService: dataSync foreground keep-alive while an agent turn runs (stops when idle)
```

## Quick start

```bash
# 1. Assemble the payload (materialize the upstream dsh run tree + this repo's packages/* + bundle patch + shims)
node scripts/assemble-payload.mjs --deploy --apply
# 2. Package the payload → app/src/main/assets/dsh-payload/{dsh.tar,dsh.version}
node scripts/package-payload.mjs --src build/payload-stage/root
# 3. Provision the engine (libnode.so, sha256-locked, eight ELF gate checks)
node scripts/provision-engine.mjs
# 4. Build (full = sideload line incl. All-files; store = SAF-only line)
./gradlew assembleFullDebug        # emulator / sideload debugging
./gradlew assembleFullRelease      # release candidate (requires signing config)
# 5. Deploy
adb install -r app/build/outputs/apk/full/debug/app-full-debug.apk
```

Environment prerequisites (D.3 checklist): IANA timezone (GMT-offset names are rejected), POST_NOTIFICATIONS on Android 13+, All-files grant (Documents/Download tabs), arm64-v8a engine
(x86_64 emulators need an ARM translation image). See [docs/安卓环境能力清单.md](docs/安卓环境能力清单.md) §D.3.

> Minimum support **Android 8.0 / API 26** (minSdk 29→26 since 111): All-files (Documents/Download) only on API 30+
> (honest 26–29 fallback); notification runtime permission requested on 33+ only (<33 granted by default). Engine / PTY / bridge AAR minSdk 24.
